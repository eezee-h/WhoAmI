# Who Am I?

`Who Am I?`는 개인 포트폴리오 페이지를 만들고 직접 관리할 수 있는 웹 서비스입니다.

회원가입 후 사용자는 로그인하여 프로필, 경력, 활동, 프로젝트, 연락처를 직접 수정할 수 있습니다.

## 주요 기능

- 사용자별 공개 포트폴리오 페이지
- 회원가입 및 로그인
- 프로필, 키워드, 이미지 편집
- 경력, 학력, 수상, 자격증 등 아카이브 관리
- 대외활동 및 프로젝트 카드 관리
- 커스텀 카드 섹션 추가
- 카드 상세 내용에 텍스트, 이미지, 영상, 링크 추가
- 카드 상세 사진 붙여넣기, 표시 크기 선택 및 확대 보기
- 연락처와 색상 테마 관리
- Docker Compose 기반 실행

## 기술 스택

| 영역 | 기술 |
| --- | --- |
| Frontend | Next.js 15, React 19, TypeScript |
| Backend | Spring Boot 3.3, Java 21 |
| Database | PostgreSQL 16 |
| Infra | Docker, Docker Compose |

## 실행

프로젝트 루트에서 실행합니다.

```bash
docker compose up -d --build
```

기본 주소:

- Frontend: `http://localhost:3000`
- Backend: `http://localhost:8080`
- PostgreSQL: `localhost:5432`

중지:

```bash
docker compose down
```

## 관리자 편집

관리자는 공개 페이지에서 편집 모드를 켜고 내용을 수정합니다.

- `편집 시작` / `편집 종료`로 보기 모드와 편집 모드를 전환합니다.
- `편집 종료`는 로그인 상태를 유지하고 편집 UI만 끕니다.
- 완전히 인증을 해제하려면 `로그아웃`을 사용합니다.

카드 상세 사진 편집:

- `+ 이미지`를 누르면 자동으로 선택된 빈 사진 박스가 생깁니다. 사진·캡처를 복사한 뒤 `Ctrl+V` / `⌘V`로 붙여넣거나, 박스 안의 `이미지 불러오기`로 파일을 선택합니다.
- 사진은 해당 박스 자리에 들어갑니다. 여러 파일을 선택하면 첫 사진은 박스를 채우고 나머지는 바로 뒤에 추가됩니다. 빈 박스도 이동·삭제할 수 있으며 방문자 화면에는 표시되지 않습니다.
- 빈 박스가 아닌 상세 편집 영역에 사진을 붙여넣으면 기존처럼 맨 아래에 추가됩니다.
- 사진 크기를 `작게 / 보통 / 전체` 중에서 선택합니다. 기본값은 `보통`이며, 선택한 크기는 저장 후에도 유지됩니다.
- 사진 블록의 가로폭을 기준으로 `작게`는 50%, `보통`은 75%, `전체`는 100%로 표시합니다. 모든 크기에서 세로는 높이 제한 없이 원래 비율을 유지하며, 모바일에서도 같은 비율로 적용됩니다.
- `작게 / 보통`에서는 사진별로 `왼쪽 / 가운데 / 오른쪽` 정렬을 선택할 수 있습니다. 기본은 `가운데`이며 저장 후에도 유지됩니다. `전체`에서는 정렬 버튼을 숨기지만, 크기를 다시 줄이면 이전 정렬이 적용됩니다.
- 나란히 배치한 두 사진을 가운데로 모으려면 왼쪽 사진은 `오른쪽`, 오른쪽 사진은 `왼쪽` 정렬로 설정합니다.
- 사진을 누르면 확대창이 열리며, `실제 크기로 보기`로 전환해 스크롤하며 볼 수 있습니다.
- 사진 붙여넣기는 클립보드에 이미지 자체가 들어 있을 때 지원합니다. 사진 주소나 일반 텍스트 붙여넣기는 기존 방식으로 동작합니다.
